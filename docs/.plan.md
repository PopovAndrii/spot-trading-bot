**Interface fields (Part 1), in order — text is grounded in the in-app hints:**
- **Long / Short** — strategy direction (radio). Long buys the dips, Short sells the rallies.
- **Available balance** (`field-deposit`) — pulled from the exchange on Long/Short click; the grid is sized from it; may be reduced, never inflated past what you hold.
- **Order Size** (`field-orderSize`) — size of the first order; ≥ the exchange minimum, usually +5%.
- **Profit** (`field-profit`) — target profit %; typical ≤1%, optimal 0.2–0.5%.
- **Exchange commission** (`field-commission`) — Binance ~0.25% (0.1% with the bonus).
- **Progression strategy** — Progressive (fixed multiplier) vs Fibonacci (Fibonacci sequence) for how order size grows down the grid; Fibonacci most effective.
- **Martingail** (`field-martingail`) — sizes the gap of the closing order / end-of-series; high = triggers often but burns balance, low = wide grid + good overlap but the last order sits far. Ranges: min 25–35, optimal 35–80, excellent 80–100+.
- **Progressive step** (`field-fibonachiStep`) — overlap % between rungs (drops on Long / rises on Short); >20% = lower risk but rarer fills.
- **Indent price** (`field-indent`) — gap between the first order and the current price.
- **Active orders** (`field-activeOrders`) — how many orders sit live at once; changeable while running.
- **Request frequency** (`field-requestFrequency`) — polling period for the series; changeable while running.
- **Restart** (switch) — restart after the current series finishes; changeable while running.
- **Calculate / Save / Start-Stop** — buttons: build the grid, persist it, run/stop the cycle.
- **Stream** — the live price ticker beside Start/Stop (e.g. `BNBUSDT 556.15`).
