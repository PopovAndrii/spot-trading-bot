## 1. ⛔ Принятый риск · P2 · Деньги во `float` + `toFixed` · L
**Где:** `lib/calculator.js`, `lib/rebalanceClose.js`, `lib/job.js`.
**Проблема:** все расчёты в double, округление `toFixed`. Погрешность сейчас
прикрыта floor по `stepSize`/`tickSize`. На больших объёмах/мелких тиках возможна
накопленная погрешность.
**Статус:** припаркован осознанно. Страховка готова — golden-тест
`test/calculatorGolden.test.js` + эталон `test/fixtures/calculatorGolden.json`
фиксируют вывод `Calculator.build()` побитово (long/short, progressive/fibonacci,
indent); любой сдвиг последней цифры завалит тест до деплоя.
**Шаг, если возьмёмся:** `decimal.js` либо целочисленная арифметика в тиках/степах.
Поведенческий рефактор с риском для денег — только по явному запросу, с полным
набором golden-тестов до/после.

## 2. Известный принятый риск · P2 · Орфан-остаток на стороне НАБОРА позиции
**Где:** сценарий: частичный entry-ордер (BUY для long) + одновременное исполнение
закрытия → на балансе base зависает недокупленный остаток, не привязанный к циклу.
**Смягчение в коде:** в DONE-ветке `recoveryStats(obj)` считает `stranded`; при
`autoRestart && stranded` авто-рестарт отменяется (не усредняемся поверх застрявших
монет) + уведомление с точным объёмом/курсом безубытка.
**Решение (by-design):** авто-реконсиляцию НЕ делаем — ручное восстановление,
решение за пользователем. Возможный путь, если понадобится: зеркало `rebalanceClose`
для стороны набора (чистая функция + тесты, отдельной задачей с testnet-верификацией).

## Что НЕ является проблемой (проверено, осознанные решения)

- **Donate-адреса захардкожены в `lib/donations.js`** — by design: одни на всех, кто
  развернёт копию. `uri:''` → QR ведёт на `#id` (no-op) — сеть выбирается в кошельке.
- **Cancel/Delete по всему символу** (роботские+ручные неразличимы) — by design;
  доработка `newClientOrderId` (отличать роботские ордера от ручных) отложена до
  переноса управления в таблицу реальных ордеров.
- **CSP выключен в dev** — browser-sync грузит socket.io с отдельного порта; CSP —
  фича прода (комментарий в `app.js`).
- **Одна сеть на процесс** (real ИЛИ testnet) — достаточно для одно-пользовательского
  робота; зафиксировано в `InvokeApi`.
